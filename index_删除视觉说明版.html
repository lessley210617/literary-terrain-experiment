这是一个面向文学直觉研究的“文学地形图构建实验”：你先建立自己的文本池，再让“机器”在不使用体裁、流派、主题等文学宏的前提下，按文本结构绘制地形图；随后你再以人类读者的身份引入文学宏，对两种地图进行比较。

How to Use This Experiment

核心逻辑不变：文本池 → 机器无宏地图 → 人类文学宏地图 → 宏约束重绘 → 比较与报告。

1. 自建文本池

你可以输入自己的文本，也可以导入纯文本文件，建立可重复使用的文本库。

2. 勾选文本进入实验

建议每次选 3—12 篇文本，既便于比较，也不会让人类分组负担过重。

3. 生成机器地图

机器暂时不使用“现实主义、现代主义、女性书写”等宏，而是按结构特征聚类。

4. 书写人类宏

你再以读者身份引入自己的文学宏，说明为什么这样命名，以及这个命名遮蔽了什么。

5. 宏约束重绘

让机器在第二轮允许使用部分人类宏，观察这种约束究竟是帮助理解，还是压窄发现能力。

6. 导出研究报告

最终会生成可复制、可下载的实验记录，适合论文、课堂或展示使用。

Machine Map Without Macros

先暂时不使用体裁、流派、主题、作者、时代等人类文学宏，只根据文本结构生成地形。

Human Literary Macro Map

在这里你作为人类读者主动使用文学宏。重点不只是贴标签，而是解释：这个宏压缩了什么，又遮蔽了什么？

你可以使用传统概念，也可以创造自己的概念，例如“欲望失败结构”“低可见性创伤叙事”“被延迟的成长”。
